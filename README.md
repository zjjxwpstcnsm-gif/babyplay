# 泡泡气球乐园

面向 3–5 岁小朋友的 PC Web 互动玩具。React + TypeScript + Vite，Canvas 彩纸动画，Web Audio 本地音效，无后端。

## 运行

安装 Node.js 22.12+ 和 pnpm 11，然后：

```sh
cd game
pnpm install
pnpm dev
```

在浏览器打开终端显示的本地地址。生产构建：`pnpm build`，本地检查构建：`pnpm preview`。`game/dist` 可部署到静态网站服务，资源使用相对构建路径。

## 玩法

- 首页：点击「开始玩」，或直接拍气球、按任意普通按键开始。
- 气球乐园：鼠标、触摸、任意普通按键拍气球。音乐、彩虹、动物、魔法、礼物、三次拍击的大气球；黄色普通气球轻轻躲一次。每十次拍破出现兔兔、彩虹、小火车或恐龙，无限循环，没有失败和倒计时。
- 气球的三种玩法：惊喜拍拍、音乐气球、星夜魔法。七彩小钢琴可以点击弹奏；音乐玩法中也可按 A/S/D/F/G/H/J（儿童锁中普通按键会拍音乐气球）。星夜拍击有发光烟花拖尾。
- 泡泡浴：独立海底场景，约 28 个大泡泡，随拍随补；按住鼠标或单指拖动可以连续扫泡泡，附近泡泡会连锁绽放。
- 小动物乐园：八位小伙伴可以摸摸、喂点心、哄睡和叫醒。动物屋与乐园共享同一套角色。
- 泥坑派对：乔治带着恐龙玩偶来做客，点角色或按普通按键跳泥坑；支持一起跳、落地泥花和可开关的小雨。跳过泥坑的朋友会住进动物屋，乔治也会出现在动物气球里。
- 大惊喜：柔和彩虹、完整毛绒小火车巡游、优先遇见尚未找到的动物。游戏暂停时，正在播放的惊喜和连锁计时一起暂停。
- 声音：原创柔和循环旋律、分色音阶；家长可分别控制音乐、提示语音和总声音。
- 我的动物屋：在气球里找到的动物会留在这里，再次打开仍在。
- 家长设置：音效、中文语音、音量、飘动速度、安静动画；最多六张本地照片和称呼。
- 儿童锁：全屏、增强按键保护（浏览器支持并授权时）、触控板事件防误触、意外退出后恢复。长按右上角小锁三秒，再完成家长算式验证退出。[操作与保护范围](./CHILD_LOCK.md)。

全屏入口现在统一经过儿童锁。系统多指切换桌面/应用需要家长在电脑设置中关闭；锁定说明中提供 Mac 与 Windows 指引。网页不会宣称已锁定系统手势。

## 验证

Node.js 22.12+ 的几何边界检查：`node --experimental-strip-types --test tests/gameMath.test.mjs`。

安装 agent-browser 并启动本地开发服务后：`node tests/browser.mjs`。可用 `AGENT_BROWSER_BIN` 指定 CLI 路径。该测试仅接受 localhost/127.0.0.1，不操作线上数据；请使用独立测试浏览器。覆盖拖动连锁、暂停、钢琴、星夜、动物互动、泥坑跳跃/雨天/乔治收集、儿童锁、失焦恢复和家长验证。

音效使用 Web Audio 合成，首次操作后启用；中文语音使用浏览器/操作系统的语音合成服务，效果与中文语音包的可用性有关。照片经浏览器缩成 256×256 后保存于此浏览器的 localStorage，不会由游戏上传到服务器；换浏览器或清除网站数据不会保留照片和动物。语音服务是否离线由浏览器决定。

所有游戏视觉资源本地加载，原创背景和兔兔插画位于 `game/public/art`。动物屋、动物气球和惊喜奖励共用八位透明角色插画；小屋有独立的暖光背景。新增素材生成提示词保存在 `art-prompts-v2.json`、`art-prompts-v3.txt` 与 `art-prompts-peppa.txt`。`game/.openai/hosting.json` 保存 Sites 部署标识，不包含密钥。
