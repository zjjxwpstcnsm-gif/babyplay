# 泡泡气球乐园

面向 3–5 岁小朋友的 PC Web 互动玩具。React + TypeScript + Vite，Canvas 彩纸动画，Web Audio 本地音效，无后端。

## 运行

安装 Node.js 22.12+ 和 pnpm 11，然后：

```sh
cd game
pnpm install
pnpm dev
```

在浏览器打开终端显示的本地地址。生产构建：`pnpm build`，本地检查构建：`pnpm preview`。`game/dist` 可部署到静态网站服务，资源使用相对构建路径。

## 玩法

- 首页：点击「开始玩」，或直接拍气球、按任意普通按键开始。
- 气球乐园：鼠标、触摸、任意普通按键拍气球。音乐、彩虹、动物、魔法、礼物、三次拍击的大气球；黄色普通气球轻轻躲一次。每十次拍破出现兔兔、彩虹、小火车或恐龙，无限循环，没有失败和倒计时。
- 泡泡浴：约 28 个大泡泡，随拍随补。
- 小动物乐园：点击七种动物听声音。
- 我的动物屋：在气球里找到的动物会留在这里，再次打开仍在。
- 家长设置：音效、中文语音、音量、飘动速度、安静动画；最多六张本地照片和称呼。
- 儿童锁：全屏、增强按键保护（浏览器支持并授权时）、触控板事件防误触、意外退出后恢复。长按右上角小锁三秒，再完成家长算式验证退出。[操作与保护范围](./CHILD_LOCK.md)。

音效使用 Web Audio 合成，首次操作后启用；中文语音使用浏览器/操作系统的语音合成服务，效果与中文语音包的可用性有关。照片经浏览器缩成 256×256 后保存于此浏览器的 localStorage，不会由游戏上传到服务器；换浏览器或清除网站数据不会保留照片和动物。语音服务是否离线由浏览器决定。

所有游戏视觉资源本地加载，原创背景和兔兔插画位于 `game/public/art`。动物屋、动物气球和惊喜奖励共用七种透明毛绒动物插画；小屋有独立的暖光背景。新增素材生成提示词保存在 `art-prompts-v2.json`。`game/.openai/hosting.json` 保存 Sites 部署标识，不包含密钥。
