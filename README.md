# 泡泡气球乐园

面向 3–5 岁小朋友的 PC Web 互动玩具。React + TypeScript + Vite，Canvas 彩纸动画，Web Audio 本地音效，无后端。

[打开在线乐园](https://zjjxwpstcnsm-gif.github.io/babyplay/) · [GitHub 仓库](https://github.com/zjjxwpstcnsm-gif/babyplay)

## 运行

安装 Node.js 24 和 pnpm 11，在仓库根目录执行（本地工作区的代码位于 `game/`）：

```sh
pnpm install
pnpm dev
```

在浏览器打开终端显示的本地地址。生产构建：`pnpm build`，本地检查构建：`pnpm preview`。`dist` 可部署到静态网站服务，资源使用相对构建路径。推送 `main` 后，`.github/workflows/pages.yml` 自动构建并部署到 GitHub Pages。

## 玩法

- 首页：点击「开始玩」，或直接拍气球、按任意普通按键开始。
- 认字气球：数字 0–9、字母 A–Z、16 个入门汉字。一次一个气球，12 秒轻缓漂浮循环，无倒计时和失败。按匹配的键盘字符，或点击下方相同字符的屏幕按键才会击破；点气球只听读音。字母不区分大小写；汉字通过屏幕选项或对应的键盘 1/2/3 选择。答错温和提示，答对庆祝后约 1.9 秒出现下一个，暂停时停止补球。儿童锁也保留正确按键判定。
- 影子乐园，小动物模式：点击「开启摄像头」并允许浏览器权限，脸朝向镜头，靠近时影子变大、退后时变小；横向移动也会带动影子。可选小兔、小猫、小狗、小熊、大象和小鸭。可将当前距离校准为中等，也可在未开启摄像头时用「先体验大小」滑杆体验。识别使用本地 MediaPipe 模型，按画面中最大人脸的宽度估计远近，并非精确深度测量；请让小朋友面向镜头、光线充足，家长在一旁陪同。识别不到人脸时保留最后大小并提示。暂停、页面隐藏或离开场景会关闭摄像头，继续时需重新开启。画面不拍照、不保存、不上传。
- 影子乐园，真人模式：切换到「真人影子」并开启摄像头，实时分离人物与背景，将实际头部、身体、手臂轮廓画成镜像影子。位置、动作和大小都直接跟随每帧人物画面，靠近自然变大、远离自然变小；无需人脸校准。人物进入画面、光线充足时效果更清楚，遮挡、复杂背景、过远距离或出画的肢体会影响识别。镜头中的多个人物可能一起成为影子。人物离开画面时清除轮廓；两种模式可复用同一个摄像头，切换时释放旧识别模型。画面不拍照、不保存、不上传。
- 气球乐园：鼠标、触摸、任意普通按键拍气球。音乐、彩虹、动物、魔法、礼物、三次拍击的大气球；黄色普通气球轻轻躲一次。每十次拍破出现兔兔、彩虹、小火车或恐龙，无限循环，没有失败和倒计时。
- 气球的三种玩法：惊喜拍拍、音乐气球、星夜魔法。七彩小钢琴可以点击弹奏；音乐玩法中也可按 A/S/D/F/G/H/J（儿童锁中普通按键会拍音乐气球）。星夜拍击有发光烟花拖尾。
- 泡泡浴：独立海底场景，约 28 个大泡泡，随拍随补；按住鼠标或单指拖动可以连续扫泡泡，附近泡泡会连锁绽放。
- 小动物乐园：八位小伙伴可以摸摸、喂点心、哄睡和叫醒。动物屋与乐园共享同一套角色。
- 泥坑派对：乔治带着恐龙玩偶来做客，点角色或按普通按键跳泥坑；支持一起跳、落地泥花和可开关的小雨。跳过泥坑的朋友会住进动物屋，乔治也会出现在动物气球里。
- 大惊喜：柔和彩虹、完整毛绒小火车巡游、优先遇见尚未找到的动物。游戏暂停时，正在播放的惊喜和连锁计时一起暂停。
- 声音：原创柔和循环旋律、分色音阶；家长可分别控制音乐、提示语音和总声音。
- 我的动物屋：在气球里找到的动物会留在这里，再次打开仍在。
- 家长设置：音效、中文语音、音量、飘动速度、安静动画；最多六张本地照片和称呼。
- 儿童锁：全屏、增强按键保护（浏览器支持并授权时）、触控板事件防误触、意外退出后恢复。长按右上角小锁三秒，再完成家长算式验证退出。[操作与保护范围](./CHILD_LOCK.md)。

全屏入口现在统一经过儿童锁。系统多指切换桌面/应用需要家长在电脑设置中关闭；锁定说明中提供 Mac 与 Windows 指引。网页不会宣称已锁定系统手势。

## 验证

运行 `pnpm test` 检查几何边界、字符选项和按键映射、远近缩放与边界。

安装 agent-browser 并启动本地开发服务后：`node tests/browser.mjs`。可用 `AGENT_BROWSER_BIN` 指定 CLI 路径。该测试仅接受 localhost/127.0.0.1，不操作线上数据；请使用独立测试浏览器。覆盖拖动连锁、暂停、钢琴、星夜、动物互动、泥坑跳跃/雨天/乔治收集、儿童锁、失焦恢复和家长验证。

新功能浏览器检查：`node tests/learning-shadow-browser.mjs`。覆盖错误/正确字符、字母大小写、汉字数字按键、儿童锁、暂停、六种动物、权限拒绝、真实模型远近识别、校准、人脸丢失和摄像头清理。测试在专用会话中用公开的 MediaPipe portrait 测试图像生成模拟摄像头，不使用真实摄像头；默认下载测试图像，也可通过 `BABYPLAY_FACE_FIXTURE` 提供本地图片。`BABYPLAY_TEST_URL` 可指定本机开发服务器。

真人影子检查：`node tests/person-shadow-browser.mjs`。使用公开的 MediaPipe pose 测试图片模拟视频，验证真实分割模型、透明背景、镜像、轮廓位置变化、远近大小变化、两种模式切换、人物离开、暂停/导航/取消启动时清理摄像头及桌面/手机布局。也可用 `BABYPLAY_PERSON_FIXTURE` 指定本地测试图片，测试不会访问真实摄像头。

音效使用 Web Audio 合成，首次操作后启用；中文语音使用浏览器/操作系统的语音合成服务，效果与中文语音包的可用性有关。照片经浏览器缩成 256×256 后保存于此浏览器的 localStorage，不会由游戏上传到服务器；换浏览器或清除网站数据不会保留照片和动物。语音服务是否离线由浏览器决定。

所有游戏视觉资源本地加载，原创背景和兔兔插画位于 `public/art`。动物屋、动物气球和惊喜奖励共用八位透明角色插画；小屋有独立的暖光背景。新增素材生成提示词保存在 `art-prompts-v2.json`、`art-prompts-v3.txt` 与 `art-prompts-peppa.txt`。`.openai/hosting.json` 保存 Sites 部署标识，不包含密钥。
